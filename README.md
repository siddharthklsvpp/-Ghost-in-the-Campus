
# 👻 Ghost in the Campus

A campus FAQ chatbot that helps students get answers about college timetables, labs, campus rules, and other campus-related questions.

## ✨ Features
- Campus FAQ assistance
- Simple web interface
- Virtual campus ghost chatbot

## 🛠️ Technologies
- HTML
- Additional technologies to be updated based on the project implementation

## 🚀 How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.

## 📂 Project Files
- `index.html` — Web interface
- `campus-ghost.zip` — Project archive

## 🎓 Project Type
Student project — Ghost in the Campus.
